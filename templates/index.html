Magnet ↔ Torrent

Batch conversion between .torrent files and magnet links.

Torrent → Magnet

Drop or pick one or more .torrent files. Conversion runs in your browser session against the server.

Magnet → Torrent

Paste one magnet URI per line. The server joins the swarm via DHT and downloads metadata (BEP-9). May take a while per URI.

    Magnet → Torrent requires libtorrent on the server and live peers in the swarm.
